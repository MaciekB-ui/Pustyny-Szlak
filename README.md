# Pustynny Szlak

## Jak uruchomić grę
1. Otwórz projekt w Visual Studio Code
2. Kliknij plik `main.py`
3. Uruchom go przyciskiem „Run Python File” (prawy górny róg)
4. Gra działa w terminalu + oknie Turtle

---

## O co chodzi w grze
W grze sterujesz łazikiem poruszającym się po pustynnej mapie.  
Twoim celem jest odnalezienie ukrytego artefaktu i powrót do punktu startowego (0,0).

W trakcie eksploracji:
- zbierasz zasoby (paliwo, części silnika, pancerza)
- ulepszasz pojazd
- unikasz burz piaskowych
- możesz znaleźć fragmenty mapy, które pokazują przybliżone położenie artefaktu

---

## Sterowanie
W trakcie gry wpisujesz komendy w terminalu:

1 – ruch do przodu  
2 – obrót w prawo (45°)  
3 – obrót w lewo (45°)  
4 – kopanie  
9 – zakończenie wyprawy  

Każda akcja wymaga zatwierdzenia Enterem.

---

## Cel gry
- znaleźć artefakt
- wrócić na start (0,0)
- zdobyć jak najlepszy wynik punktowy
